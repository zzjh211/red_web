作品简介 · 关于本站

这里汇总本参赛作品的选题定位、内容结构、设计说明与原创声明。本页内容亦可直接作为提交材料中的"作品简介"。

INTRODUCTION

作品简介

选题定位

以"党史与革命历史"为主线，系统回望从中共一大到新时代的光辉历程，主题鲜明、符合主流价值观与大赛主旨。

内容结构

由首页、党史历程、红色人物、红色精神、关于本站五个页面组成，层次清晰、文件分类存放，目录深度不超过三层。

技术实现

纯静态网页（HTML / CSS / 原生 JavaScript），无外部框架依赖，本地链接全部采用相对路径，兼容主流浏览器。

交互特色

时间轴点击展开、人物卡片翻转、滚动入场动画、Hero 视差与标语轮播，并配有原创背景音乐，交互性强、体验流畅。

DESIGN

设计说明

一、设计理念

以经典"中国红 + 描金"的庄重视觉语言，营造严肃而不失温度的红色氛围；版式以衬线标题搭配无衬线正文，强调可读性与秩序感，突出"历史感"与"纪念性"。

二、色彩与字体

  • 主色：中国红（#C8102E）与深红（#7A0C16），辅以描金（#C9A24B / #E8C977）；
  • 字体：标题使用思源宋体 / 宋体类衬线字族，正文使用思源黑体 / 微软雅黑类无衬线字族；
  • 图形：Logo、Hero 剪影、板块图标与分隔纹样均使用矢量 SVG，离线可用、清晰锐利。

三、工程约束

  • 图片、音频等资源分别存放于 images/ 与 music/ 目录；
  • 所有本地链接使用相对路径，目录层级不超过三层；
  • 仅使用原生技术栈，未引入任何第三方库，确保评审环境（Edge 90+）正常打开。
NOTES

创作手记

做这个网站，也是一次重新走近历史的过程。

1为什么选党史

题材权威、素材可考，是最不易踩内容红线的方向；对青年而言，回望来路也比空谈口号更有重量。

2页面怎么搭

以"时间—人物—精神"三条线索串起全站，力求层次清晰、互有呼应，而不是零散堆砌。

3一点小坚持

所有人物与事件文案只写公开权威史实，不虚构引语；背景音乐为原创曲目，无第三方版权争议。

4还想补的

如果时间允许，希望加入更多地方红色资源与互动问答，让"展示"不止于看，更能让人参与进来。
